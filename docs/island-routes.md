# Островные морские линии

Этот документ описывает сохранённые игровые круги. Для подтверждённых книжных сообщений, железных дорог и расписаний см. [атлас источников](transport-sources.md). В частности, после сверки глав 523 и 533 для Симиима подтверждено регулярное пассажирское сообщение с Байамом.

В сети 22 портовых и рейдовых стоянки, 5 круговых линий и 26 переходов. Корабли заходят на каждую остановку по порядку, стоят перед отправлением и после полного круга возвращаются к началу.

Названия и расположение сверены с [исходной картой мира книги](https://github.com/Phishinabowl/LoTM-Re-Read-Analysis/blob/608e48939ec352876ae919213a236592f46d982c/Artwork/page-assets/maps/lotm-world-map.jpg). Линии и расписания созданы для игры: они не выданы за маршруты, дословно описанные в романе. У островов без подписанной гавани указан рейд.

## Линии

### Почтовая линия Лоэна

Порт Приц → Порт Дамир → Порт Банси → Порт Тиана → Байам → Порт Приц

Крейсерская скорость: 12 узлов. Стоянка перед каждым отправлением: 60 игровых минут.

### Западный Рорстед и Южный континент

Байам → Порт Дилимиус → Рейд острова Вэйпойнт → Порт Халман → Порт Эскелсон → Порт Пото → Рейд Тероса → Порт Беренс → Байам

Крейсерская скорость: 8 узлов. Стоянка перед каждым отправлением: 120 игровых минут.

### Восточные острова Рорстеда

Байам → Рейд Длиннохвостого острова → Стоянка Симиима → Порт Тоскартер → Порт Орави → Рейд Диноса → Байам

Крейсерская скорость: 8 узлов. Стоянка перед каждым отправлением: 90 игровых минут.

### Соня и архипелаг Гаргас

Порт Приц → Рейд острова Соня → Нас → Рейд острова Пасу → Порт Приц

Крейсерская скорость: 12 узлов. Стоянка перед каждым отправлением: 60 игровых минут.

### Аурак и Первобытный остров

Порт Халман → Рейд архипелага Аурак → Рейд Первобытного острова → Порт Халман

Крейсерская скорость: 8 узлов. Стоянка перед каждым отправлением: 120 игровых минут.

Доступность стоянок, связанных с событиями сюжета, задаётся ведущим кампании. Экспедиционные линии обозначают игровые морские подходы, а не регулярное сообщение со всеми опасными островами. Для района Дубового острова используется ближайший отмеченный порт Приц; отдельная неподтверждённая гавань не выдумывается.

Геометрия морских коридоров проверена по HD-изображению. Границы суши вручную учитываются в опорных точках; это подготовленная сеть, а не автоматический навигатор для произвольных маршрутов. Сетка 1500 км² на клетку и скорости парового транспорта сохраняются.
