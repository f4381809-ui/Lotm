# LotM — Живой атлас

Неофициальная игровая карта мира **Lord of the Mysteries / «Повелитель тайн»** для ведущего приключений.

## Запуск

Зависимости, сборка и API-ключи не нужны. Требуется Python 3:

```sh
cd /workspace/Lotm
python3 -m http.server 3000 --bind 0.0.0.0
```

При локальном запуске откройте адрес запущенного сервера в браузере.

## Скачать без установки

[Скачать автономную карту](downloads/LotM-Atlas.html): сохраните HTML-файл и откройте его в браузере. Карта, оформление и скрипты уже внутри; интернет не требуется.

## Управление

- **Игроки:** введите имя, выберите цвет, нажмите «Поставить игрока на карте» и укажите место кликом. Перетащите отметку, чтобы переместить игрока. Кнопка «Переместить» позволяет выбрать новое место кликом. Клик по имени в списке приближает игрока. У отметки в фокусе работают стрелки; Shift увеличивает шаг.
- **Время:** часы идут автоматически — при скорости 1× одна реальная секунда равна четырём игровым минутам. Есть пауза и скорости 5× / 15×. Кнопки «День» и «Ночь» переводят время вперёд до соответствующего периода, сохраняя порядок дней. Переход времени влияет на длительность дождя. Фон постепенно темнеет вечером и светлеет на рассвете.
- **Транспорт:** два корабля и поезд движутся туда и обратно по условным игровым маршрутам. Флажки включают и скрывают соответствующий транспорт. На паузе движение останавливается. Маршруты не претендуют на каноническую точность.
- **События:** задайте название, силу, размер и длительность дождя, затем укажите центр зоны на карте. Зону можно перемещать; событие можно завершить вручную. Дождь с ограниченной длительностью заканчивается по игровым часам. События записываются в журнал.
- **Карта:** перетаскивание — обзор; колесо мыши или кнопки + / − — масштаб; «Общий вид» возвращает обзор, сохраняя игроков и события. Esc отменяет размещение. В разделе «Места» доступны поиск, фильтры и описания; `/` открывает поиск.

Игроки, погода, журнал и настройки автоматически сохраняются в **localStorage текущего браузера**. Между устройствами и пользователями они не синхронизируются. Пока страница закрыта, игровое время не идёт. Если браузер запрещает хранение данных, сайт сообщает об этом; в таком случае изменения доступны только до перезагрузки.

## Файлы

- `index.html` — интерфейс атласа.
- `style.css` — адаптивное оформление.
- `app.js` — игроки, игровые часы, события и сохранение.
- `simulation.js` — транспорт и зоны дождя.
- `World_Map.webp` — исходная карта из репозитория.
